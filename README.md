# Taskanator
A Task managing Chatbot that uses Groq to interpret messages sent by the user, and either add a task, mark one as complete or delete it. 

Visit the Groq API webstie "https://console.groq.com/keys" to create your own API key for the code, and just paste it where "your_api_key" is here and run this line in your cmd"  setx GROQ_API_KEY "your_api_key_here"  "
